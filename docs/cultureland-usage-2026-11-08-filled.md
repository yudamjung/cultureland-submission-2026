## 먼저 알아둘 공통 사용방법

### 컬쳐캐쉬 준비

상품권을 온라인에서 사용할 때는 원칙적으로 컬쳐랜드에서 컬쳐캐쉬로 충전한 뒤 사용한다. 안심금고에 보관된 금액이 아니라 사용 가능한 컬쳐캐쉬 잔액이 있어야 한다.

### A. 직접결제·바로사용

컬쳐랜드에서 사용처로 이동 → 상품·콘텐츠 선택 → 결제 단계에서 컬쳐캐쉬 선택 → 컬쳐랜드 계정으로 잔액 조회 → 사용할 금액을 확인하고 결제한다. 일부 서비스는 자체 캐시·게임 재화를 먼저 충전한다. 사용처별 예외는 아래 항목을 따른다.

### B. 포인트·머니 전환

전환 메뉴에서 대상 선택 → 전환할 금액 입력 및 전환하기 → 컬쳐캐쉬 총 결제금액 확인 → 해당 포인트로 전환 → 제휴 서비스에서 그 포인트로 결제한다. 컬쳐랜드 본인인증 회원이어야 하고, 컬쳐랜드와 제휴사 계정의 명의가 동일해야 한다. 수수료·한도·전환 취소 가능 여부는 각 전환 화면의 현재 조건을 확인해야 한다.

### C. 쿠폰·기프트카드 구매

쿠폰 메뉴에서 브랜드 선택 → 권종·수량 선택 → 구매하기 → 총 결제금액과 수신정보 확인 → 컬쳐캐쉬 결제 → 휴대폰으로 수신한 쿠폰·코드를 해당 서비스에 등록하거나 매장에 제시한다. 지류 배송형·키오스크 교환형은 직접 사용하기 전에 배송 또는 실물 교환이 필요하다.

주의: 쿠폰을 살 수 있다는 것은 해당 브랜드에서 컬쳐캐쉬를 직접 결제수단으로 받는다는 뜻이 아니다. 쿠폰별 유효기간·제외 매장·온라인 등록 가능 여부·잔액 처리·환불 조건은 구매 화면과 발행 쿠폰 안내가 우선이다.

공통 절차 출처: 컬쳐랜드 공식 컬쳐캐쉬 사용 가이드.

## 중복 통합 기준과 확인 수준

- 로블록스는 직접결제와 기프트카드를, 한게임·넥슨은 직접 이용과 상품권 구매를 한 항목으로 합쳤다. CGV는 바로사용과 쿠폰 구매를 합쳤다. Google Play·PS Store 기프트카드의 여러 페이지 노출도 각각 한 번만 수록했다.
- 신세계 3종과 롯데 2종은 각각 한 항목 안에 권종별 절차를 보존했다. 신세계상품권과 이마트 모바일 금액권, CJ ONE 포인트와 CJ기프트카드 등 서로 다른 결제 잔액·권종은 이름이 유사해도 합치지 않았다.
- [blocked]는 사용 불가라는 뜻이 아니라 로그인 제한·연결 오류·공개 공식 근거 부족으로 세부 확인을 마치지 못한 부분이다. 공식 일반 사용법과 해당 컬쳐랜드 판매권의 조건은 구분해야 한다.
- 전환 수수료·한도는 공개 공식 페이지 관측값이다. 차감형(예: 1,000원→940원)과 별도 부과형(예: 1,000P 수령 시 1,060원 차감)을 구분했다. 과거 공지값은 적용시점을 표시했다.
